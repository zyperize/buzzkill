# Security policy

## Reporting a vulnerability

Please do not publish credentials, private keys, personal data, or full exploit details in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use that channel. Otherwise, open a minimal public issue requesting a private reporting channel without including sensitive details.

For accidental secret exposure, revoke or rotate the credential first, then report what was exposed and where it appeared so the repository history can be reviewed.

## Scope

This repository contains a local-first iOS app and development prototypes. Never add signing keys, provisioning profiles, `.env` files, device backups, Xcode archives, or personal data to the repository.
